AI 知识编译器 + Claude Agent SDK 组合拳 —— llm-wiki-claude-agent-sdk-agentic-rag 介绍

这个项目展示了 llm-wiki 怎样通过 Claude Agent SDK 变成强大的 agentic RAG：先让 AI 把所有资料读一遍、整理成彼此关联的百科全书，以后提问直接翻这本「百科」就行。

它能做什么

  • llm-wiki 自动把资料整理成结构化百科
  • Claude Agent SDK 提供智能体执行能力
  • 提问即可从知识库中精准取答
  • 含可直接照做的运行示例

怎么用

激活虚拟环境后运行 wiki_writer 脚本并提出需求，例如 python 7_wiki_writer.py --request "怎样拼搭微型车"。

适合谁 & 边界

想做企业/个人知识库的开发者。需要先有一批可整理的资料。

仓库
