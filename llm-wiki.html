让 AI 自动帮你维护个人知识库网站 —— llm-wiki 介绍

基于 Karpathy 的 llm-wiki 方法论，把网页、推特、公众号、小红书、知乎、YouTube、PDF、本地文件等各种素材，自动整理成结构清晰、彼此关联的 wiki，再用 Quartz 发布成静态网站，还能通过 Claude Agent SDK 提供 API 访问。

它能做什么

  • 多来源素材自动摄入和整理
  • 自动构建结构化、互相关联的 wiki
  • Quartz 发布为静态知识库网站
  • Claude Agent SDK 封装，提供 API 接口

怎么用

配置素材源后运行整理脚本，再用 Quartz 发布。

适合谁 & 边界

适合想搭建个人知识库的人。初次需要花时间配置素材源和环境。

仓库
