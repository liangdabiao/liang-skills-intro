想动手做一套会互动的数学课本，该怎么上手 —— mathigon-skill 介绍

你大概听说过 Mathigon——那个把数学讲得特别漂亮的免费互动在线课本网站（圆、图论、数列、概率……点一点就能玩）。如果你想自己给它加一节课、改一段内容、或者把某个互动小元件做得更好，会卡在一个现实问题：它的内容是用一套专门的写作方式写的，格式、玩法、组件都有规矩，新手容易摸不着门。

mathigon-skill 就是来解决这件事的。

你给它"我想改/加 Mathigon 的某一节内容"这样的任务，它还你一份能直接照着改的操作指引：每一步该读哪个参考文档、content.md（课程内容文件）怎么写、functions.ts（控制互动的脚本）怎么配、那些 x-开头的互动组件怎么用，避免你乱改把课本弄坏。

它到底能做什么

  • 它是一份"如何编写 Mathigon 互动课程"的操作手册，专门服务于 Mathigon 课本仓库里的内容（每门课由内容文件、互动脚本、样式三件套组成）。
  • 讲清核心心智模型：一门课是一串"步骤"，每步在内容文件里用标记声明，需要自定义互动时再配一个对应的脚本函数，两者靠名字自动对应。
  • 告诉你写不同类型内容该先读哪份参考：写文章用"Markdown 方言"指南，写互动脚本用"函数模型"指南，用 x-geopad（几何画板）、x-slider（滑块）、x-equation（方程）等组件时该查什么。
  • 覆盖怎么调用 Mathigon 自带的工具库（画点、随机、动画、滑动等），怎么跑本地预览服务器、怎么做代码检查。
  • 专门强调中文课程的非显眼规则：每个小节必须显式写英文段落标识，否则后面的小节会打不开。
  • 提醒"几何图别凭感觉乱画"：涉及长度、角度、坐标时，必须先实打实算一遍再写，避免图看着对其实错。

一个具体例子

如果你要在本地改完一门课、确认没问题，文档给出的流程大致是：

npm install        # 安装依赖（注意 registry 可能需切回官方源）
npm run lint-fix   # 自动修一修脚本格式
npm run lint       # 检查（期望 0 错误）
npm run assets     # 编译课程（留意"公式解析错误"等警告）
npm run server     # 起本地预览，打开 http://localhost:5000 点一遍

你按这个顺序跑，就能在浏览器里看到自己改的课，点"下一步"确认互动正常。

谁适合用

  • 想给 Mathigon 贡献/翻译课程的教育者、数学爱好者。
  • 老师想把自己擅长的一节数学做成互动课本。
  • 需要维护或二次开发 Mathigon 课本的技术协作人员。
  • 做互动数学内容、想借鉴其写作体系的人。

一点说明 / 小提示

这个项目是给"做 AI 工具 / 维护课本的人"用的技能（skill），而且它偏向"操作手册"性质——不是普通人点开就能用的 App，也不是自动帮你生成网页，而是指导懂一点技术的协作者正确地改 Mathigon 课本。它需要 Node.js 环境和 npm install 装依赖，且仓库本身不含服务器和组件库（来自外部 @mathigon/studio 包）。中文课程有特殊的段落标识规则，务必先读它指定的本地化参考再动手。具体命令和规则以项目内 references/ 文档为准。
