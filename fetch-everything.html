一个工具箱搞定抓取、提取、部署 —— fetch-everything 介绍

一套面向 Claude Code / OpenClaw 的高质量 Skills 合集，涵盖网页抓取、文档提取、电商数据处理、云端部署等场景，对中文平台做了专门强化。

它能做什么

  • 网页抓取与文档提取
  • 电商数据处理
  • 云端部署辅助
  • 特别强化中文平台支持

怎么用

把合集放入 skills 目录，按需让 agent 调用。

适合谁 & 边界

Claude Code / OpenClaw 用户。各技能按场景取用即可。
