对话式写出 Seedance 视频脚本和分镜 —— claudesdk-seedance-chat 介绍

基于 Claude Agent SDK 的 Web 应用，通过自然语言对话生成专业的 Seedance 2.0 视频脚本和分镜提示词，支持从故事分析到分镜脚本的全流程 AI 创作。

它能做什么

  • 对话生成 Seedance 2.0 视频脚本
  • 自动产出分镜提示词
  • 从故事分析到分镜全流程覆盖
  • Claude Agent SDK 驱动

怎么用

启动服务，描述你的故事或创意。

适合谁 & 边界

AI 视频创作者。脚本仍需根据生成效果调整。
