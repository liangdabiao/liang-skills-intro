企业微信里的 AI 客户管理工作台 —— wecomcli-crm 介绍

基于 wecom-cli 搭建的企业微信 Agent 工作台，通过 Claude Code / OpenClaw 加 Skills 实现 AI 驱动的 CRM 客户管理、消息处理和会议日程等操作。

它能做什么

  • AI 驱动的 CRM 客户管理
  • 企业微信消息处理
  • 会议日程安排
  • 基于 wecom-cli，对话即可操作

怎么用

配置企业微信 CLI 授权后，在对话中提需求。

适合谁 & 边界

使用企业微信的团队和销售。需要管理员配合配置应用。
