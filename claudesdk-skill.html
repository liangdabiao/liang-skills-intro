让 AI 读着文档，自己造一个 TikHub 助手 —— claudesdk-skill 介绍

一个探索 Claude Agent SDK 能力的实验项目：通过 Skill 系统让 AI 自己读懂 SDK 文档，然后自主构建出一个 TikHub 社交媒体数据对话 Webapp。

它能做什么

  • AI 阅读 SDK 文档自主理解用法
  • 自动构建 TikHub 社媒对话 Webapp
  • 基于 tikhub_api_skill 封装
  • 展示「技能驱动开发」的玩法

怎么用

把 claude-agent-sdk 和 tikhub 技能放入 .claude/skills，让 agent 执行搭建。

适合谁 & 边界

想体验 agent 自主开发的人。实验性质，产出需要人工验收。

仓库
