做 GEO（让 AI 推荐你的产品）从诊断到交付，它一条龙包了 —— geolook 介绍

你是个品牌方，或者帮客户做"AI 搜索优化"的服务商。你需要的不是一句"建议你优化一下内容"的空话，而是一套能落地的方案：现在 AI 怎么看你的品牌、差在哪、具体改什么、改完有没有效、最后能打包发给客户的报告。

geolook 就是来解决这件事的。

它是一套完整的 GEO（生成式引擎优化）服务流水线，从"抓官网、做体检、采样各路 AI 的答案"一路做到"生成执行工单、产出可直接部署的代码块、自动验收、打包成客户交付物"。你给它一个产品官网网址和一点介绍材料，它还你三份能直接发出去的交付文档，外加一套可部署的优化资产。

它到底能做什么

  • 站点体检：从可抓取性、长度、结构、可被抽取的"事实块"、权威信号等六个维度给官网打分，找出 AI 抓取器看不懂的硬伤（比如页面是空的、robots 封了 AI）。
  • AI 答案采样：同时问国内（智谱、豆包、DeepSeek、Kimi、MiniMax）和海外（Gemini、ChatGPT、Claude、Grok、Perplexity）多家 AI，看它们对你的品牌怎么说——国内外分开算，不混为一谈。
  • 生成带验收标准的工单：把问题变成"谁、什么时候、做到什么算完成"的执行清单，而不是泛泛的建议。
  • 产出可部署资产：直接生成 llms.txt（给 AI 看的官方事实索引）、结构化数据、定义块、FAQ 块、内容大纲等，贴进网站就能用。
  • 自动验收 + 客户交付：改完会重抓验收、自动翻工单状态，并打包成诊断 / 优化 / 执行三份正式 HTML 交付物。

一个具体例子

# 最省事：只给一个网址，全自动出三份交付物
python3 scripts/geo.py new --url https://example.com --market both

--market both 表示国内海外双市场并行（两套问题库、两套指标）。想全程点界面的话：

python3 scripts/geo.py ui   # 打开本地网页工作台，不用记命令

谁适合用

  • 给客户提供"AI 搜索优化"服务的服务商 / 代运营。
  • 自家品牌想系统做 GEO、按周期跟进效果的运营团队。
  • 做 AI 工具、要把 GEO 服务做成标准化产品的人。

一点说明 / 小提示

它是一个"AI 技能 + 命令行工具"，目标用户是服务商和会跑命令的人，不是普通用户双击即用的 APP。它要接各家 AI 的 API Key（放在 .env 里），没有联网 API 的平台走人工采样。GEO 提高的是被引用的"概率"而非"保证"，文档要求给客户写方案时必须原样写明这点；它也不做传统 SEO 排名、不买外链、不替你改网站实际代码。具体能力以项目文档为准。
