想用几百种 AI 模型画图、做视频、配音，又不想一个个去注册？—— apiz 介绍

你想让 AI 帮你画一张图、做一段视频、给视频配上自然的人声、甚至克隆一个声音？现在市面上的 AI 模型一大堆：OpenAI 的、Google 的、快手的、各种开源的，每个都要单独注册、单独配密钥、单独看文档，光是记命令就够劝退了。apiz 做的事很简单：它把这些模型全部接到一个入口，你用一套命令就能调用几百种模型。

apiz 就是来解决这件事的。

你给它一句提示词（比如"一只橘猫坐在窗台"）加上想用的模型名，它还你一张图、一段视频、一段语音或一个任务结果。

它到底能做什么

  • 文生图 / 图生图：用文字描述生成图片，或给一张图让它改成别的风格、换背景（需要传图片地址）。
  • 文生视频 / 图生视频：用文字或图片生成短视频，支持多款主流视频模型（如可灵、Seedance、Sora、Veo 等）。
  • 语音合成（TTS）：把文字变成语音，可选不同音色、语速。
  • 声音克隆：给一段样本音频，克隆出相似的声音。
  • 字幕打轴 / 语音识别：给音频或歌词，自动对齐出带时间戳的字幕；也能把录音转成文字。
  • 音乐生成：描述风格，直接生成一段背景音乐。
  • 视频解析与镜像：解析抖音等分享链接拿到无水印下载地址；把外部链接转存到它自己的 CDN。
  • 查余额、每日签到：账号是积分制，可以查余额，每天还能免费签到领积分。

一个具体例子

安装并登录后（密钥以 sk- 开头），最常用的就是生成命令：

# 生成一张图，等它完成，输出 JSON
apiz generate "一只可爱的猫" --model image4.0 --wait --json

# 生成一段视频（图生视频，成功率高的模型）
apiz generate "让这张图片的场景动起来" \
  --model fal-ai/kling-video/o3/pro/image-to-video \
  --image-url "https://..." --wait --json

# 文字转语音
apiz speak "你好，欢迎使用 AI 语音合成" --output-file output.mp3

参数里 --model 是必填的模型 ID，--image-url 用于传输入图片或音频，--wait 表示等任务跑完再拿结果。

谁适合用

  • 想省去分别注册各家 AI 平台、统一管理模型的开发者。
  • 在搭建 AI 应用、需要稳定调用多种生成模型的产品团队。
  • 把 apiz 接进 AI 编程助手（通过它提供的 MCP 服务）自动化干活的人。
  • 用 Python / TypeScript 写脚本、需要 SDK 直接调用的工程师。

一点说明

apiz 不是给完全不懂技术的人直接"说话就用"的 App，它主要是一个命令行工具（CLI），也提供 Python / TypeScript 的 SDK 和给 AI 编辑器用的 MCP 服务，需要装好命令行环境、配上 API Key 才能用。它是个"统一网关"，本身按积分收费，具体模型清单、价格和能力以 apiz models list 命令和官方文档为准。
