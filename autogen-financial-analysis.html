基于微软 AutoGen 的企业级金融分析系统 —— autogen-financial-analysis 介绍

用微软 AutoGen 多智能体框架搭建的企业级金融分析系统，整合多个金融数据源，能做财务分析、风险评估和量化投资分析。

它能做什么

  • 整合 Yahoo Finance、Alpha Vantage、Quandil 等数据源
  • 多 Agent 协作完成智能财务分析
  • VaR 计算、压力测试、蒙特卡洛模拟
  • 因子模型、投资组合优化、机器学习预测
  • 实时监控告警和交互式可视化报告

怎么用

配置数据源 API Key，启动系统后输入分析需求。

适合谁 & 边界

适合有一定基础、想学习企业级多智能体系统的开发者。
