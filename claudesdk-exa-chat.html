Claude SDK + Exa 的对话式调研平台 —— claudesdk-exa-chat 介绍

基于 Claude Agent SDK 和 Exa 搜索引擎的 AI 搜索研究平台，集成企业调研、外贸市场分析、竞品研究等技能，对话即可完成多维度搜索和深度分析。

它能做什么

  • 企业调研、外贸市场分析、竞品研究
  • 对话式多维度搜索
  • Exa 提供高质量检索能力
  • 自动生成结构化调研报告

怎么用

启动 Express 服务，在浏览器里对话提问。

适合谁 & 边界

做市场和公司调研的人。需要 Exa API 权限。
