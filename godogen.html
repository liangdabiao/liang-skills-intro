说一句话，AI 帮你做一个完整 Godot 游戏项目 —— godogen 介绍

Godogen 是一套用 Claude Code 构建完整 Godot 4 项目的技能。你描述想要的游戏，AI 自动设计架构、生成美术、写每一行代码，还会从运行的引擎里截图自检，发现不对的地方自己修（基于 htdt/godogen 二开）。

它能做什么

  • 自然语言描述 → 完整 Godot 4 项目
  • 自动设计架构、生成美术资源
  • 编写全部代码并组织好场景
  • 引擎截图自检，自动修复问题

怎么用

在 Claude Code 中加载技能，描述游戏想法即可。

适合谁 & 边界

适合独立游戏开发者。复杂大作仍需人工把控，适合快速出原型。
