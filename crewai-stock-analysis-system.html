带 Web 界面的 CrewAI 智能股票分析系统 —— crewai-stock-analysis-system 介绍

基于 CrewAI 搭建的股票分析系统，支持多维度分析、批量处理、实时监控和智能预警，并提供一个直观的 Web 管理界面。

它能做什么

  • AI 多维度股票分析
  • 批量分析多只股票
  • 价格和指标实时监控
  • 智能预警与通知 + Web 管理界面

怎么用

启动服务后在 Web 界面添加股票、查看分析和预警。

适合谁 & 边界

适合学习多智能体协作的开发者。分析结果不构成投资建议。
