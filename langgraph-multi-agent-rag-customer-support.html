能查订单、能订机票的多智能体客服系统 —— langgraph-multi-agent-rag-customer-support 介绍

这个项目用 LangChain + LangGraph 搭了一个多智能体客服，能处理航班、租车、酒店预订等旅行问答，还对接了 WooCommerce 商城，可以查商品、查文章、提交表单、查订单。

它能做什么

  • 多智能体 + RAG 架构的对话式客服
  • 处理机票、租车、酒店预订和行程推荐
  • 对接 WooCommerce：商品/文章/订单查询、表单提交
  • 适合照着改成自己行业的客服

怎么用

配置好 API Key 和 WooCommerce 地址，启动后端后在网页对话。

适合谁 & 边界

适合想自己做客服系统的开发者。需要一定 Python 基础来对接自己的业务。
