Skill 是程序，MCP 是库，LLM 是语言 —— simple-agentic-stack 介绍

一个基于 MCP 和 Skill 驱动的 AI Agent 编排系统：LLM 按自然语言写成的 Skill，一步步调用 MCP Server 提供的工具，完成复杂的多数据源联动任务。

它能做什么

  • Skill + MCP 双层编排
  • 多数据源联动任务
  • 概念清晰，方便学习 agent 本质
  • 轻量易扩展

怎么用

写好 Skill、配好 MCP Server，让 LLM 按流程执行。

适合谁 & 边界

想理解 MCP / Skill 协作方式的开发者。
