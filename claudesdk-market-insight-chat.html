对话式用户需求洞察与机会分析 —— claudesdk-market-insight-chat 介绍

基于 Claude Agent SDK 的用户需求洞察平台：输入产品或服务，系统调用洞察技能执行三段式框架（用户画像 → 情绪洞察 → 产品机会），10 分钟产出可落地的分析。

它能做什么

  • 三段式洞察框架自动执行
  • 输出用户画像、情绪动因和产品机会
  • 对话式操作，无需写代码
  • 基于 Claude Agent SDK

怎么用

启动服务，输入产品描述即可。

适合谁 & 边界

产品、运营和创业者。结论适合作为方向参考。
