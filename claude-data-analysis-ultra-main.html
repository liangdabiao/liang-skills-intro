小白一键做互联网/电商数据分析 —— claude-data-analysis-ultra-main 介绍

拉新、留存、促活、转化、A/B test、用户分析……这些互联网和电商最常用的分析，被打包成 Claude Code 里的一套技能。上传数据、说一句话，分析结果就出来了，不用自己写代码。

它能做什么

  • 覆盖拉新、留存、促活、推荐、转化等互联网常见分析
  • 支持 A/B test 和用户分析
  • 对话式操作，小白也能用
  • 基于 Claude Code agent 自动完成取数和分析

怎么用

在 Claude Code 中加载该技能，上传数据文件后用大白话提需求。

适合谁 & 边界

适合运营、产品、电商从业者。复杂定制化分析仍需懂数据的人把关。
