对话里调 54 个技能的亚马逊 AI 助手 —— claudesdk-amazon-skills-chat 介绍

基于 Claude Agent SDK 的亚马逊卖家全链路 AI 助手，集成 54 个专业技能。通过自然语言对话就能完成选品调研、关键词挖掘、Listing 优化、FBA 费用计算、PPC 广告等全链路工作。

它能做什么

  • 54 个亚马逊专业技能一站集成
  • 自然语言对话完成全链路运营工作
  • 覆盖选品、关键词、Listing、FBA、PPC
  • 浏览器 ↔ 服务端 ↔ SDK 架构清晰

怎么用

启动 Express 服务，浏览器打开后直接对话。

适合谁 & 边界

亚马逊卖家和想学习 Claude Agent SDK 的开发者。
