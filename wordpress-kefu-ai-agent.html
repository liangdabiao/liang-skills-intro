两个文件，给自己的 WordPress 加个 AI 客服 —— wordpress-kefu-ai-agent 介绍

不用 Coze、不用 Dify，这个项目用两个简单文件就给 WordPress（或其他网站）加上一个能真正干活的自适应智能客服，稍微配置即可上线。

它能做什么

  • 极简的自适应智能客服
  • 两个文件即可部署
  • 适合 WordPress 也适合其他站点
  • 自己掌控，不依赖第三方平台

怎么用

把文件放到站点，填好模型 API 配置即可。

适合谁 & 边界

适合独立站站长和程序员。需要一点点代码配置能力。
