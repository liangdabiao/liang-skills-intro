亚马逊选品全家桶，一个 skill 调齐四大数据源 —— amazon-sorftime-research-mcp-skill 介绍

做亚马逊最头疼的不是没数据，而是数据散在 Sorftime、西柚、Sif、卖家精灵好几个平台，来回切换、手动拼报告。这个项目把它们全部打包成一套 agent skill，你说一句话，它直接出完整的穿透分析报告。

它能做什么

  • Listing 全维度穿透分析：文案、关键词、评论、流量一次看透
  • 全品类分析 + 关键词分析 + 差评分析 + 市场调研
  • 整合 Sorftime、西柚、Sif、卖家精灵四类 MCP 数据源
  • 可在 Codex / Claude Code 等 agent 里直接调用

怎么用

装好对应 MCP 后，直接对 agent 说「帮我分析这个 ASIN / 这个类目」即可。

适合谁 & 边界

适合亚马逊卖家和运营。前提是各数据源账号和 MCP 要先配好，它本身不提供数据。
