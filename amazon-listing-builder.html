想写出能打的亚马逊 Listing？让 AI 按新算法帮你打造 —— amazon-listing-builder 介绍

做亚马逊，"堆关键词"的老办法正在失效。现在系统看的是语义、买家看的是答案、AI 助手看的是匹配度——你标题埋大词、五点写功能，转化反而上不去。amazon-listing-builder 就是来解决这个的：它按 Cosmo 语义算法和 Alexa/Rufus 对话式购物的新逻辑，用"先分析、再生成、最后校验"的工程化流程，把你的 Listing 从"关键词堆砌"升级成"语义覆盖 + 需求证据 + 答案型内容"。

它到底能做什么

  • 八步工作流：关键词分层词库 → 用户问题库 → 卖点证据库 → 标题 → 五点 → 描述/A+ → Search Terms → QA。
  • 多版本草稿：标题、五点、A+、QA 至少出 3 版可对比，不再一笔定稿。
  • 四维校验：合规、关键词覆盖、语义覆盖、转化逻辑，四项报告把关。
  • 真实案例内置：抗 UV 户外仿真植物、down filled pillows QA 等可直接借鉴。
  • 五大误区检查：常见 Listing 踩坑点自动排雷。

怎么用

你不用背流程。装好技能后直接说需求：

场景 1：上一款新品要写全套文案 你：我要上一款瑜伽垫，把标题、五点、A+ 和问答都写出来。 AI：它先分析类目和痛点，再生成多版草稿，最后做一遍校验，产出的内容适配新的语义搜索，你拿去就能用。

场景 2：老 Listing 改造 你：这条老 Listing 转化差，帮我按新算法重做。 AI：重新做词库和证据库，输出升级版标题五点，告诉你改了什么、为什么。

谁适合用

  • 亚马逊美国站等站点的运营、Listing 优化师。
  • 产品开发、跨境营销人员。
  • 想蹭上 Cosmo / Alexa / Rufus 新算法红利的卖家。

一点说明

本技能核心数据走卖家精灵 MCP（如关键词量、竞品详情），浏览器仅作补充。具体配置以 SKILL.md 为准；没配卖家精灵账号，部分数据拉不到。
