两个智能体合作写图文并茂的帖子 —— deep-search-write 介绍

一个轻量 AI 写作方案：写作智能体负责成文，知识库智能体负责找资料、配内容，两者合作产出真正可用的公众号、小红书或博客帖子。

它能做什么

  • 写作 Agent + 知识库 Agent 双角色协作
  • 自动配图、配资料
  • 适合公众号、小红书、博客
  • 方案轻量，容易接入

怎么用

输入选题，两个 Agent 自动配合产出初稿。

适合谁 & 边界

自媒体创作者。AI 初稿建议人工润色。
