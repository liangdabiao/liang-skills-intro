钉钉版 AI 效率系统：10 大工作流 —— dingtalk-cli-workflow 介绍

基于 Claude Code / OpenClaw 技能加钉钉 CLI（dws）搭建的个人 AI 效率基础设施，把飞书版的 10 大工作流完整迁移到钉钉生态。

它能做什么

  • 10 个钉钉工作流 Skill
  • 通过钉钉 CLI 操作各模块
  • 飞书版的完整钉钉迁移
  • 个人效率基础设施

怎么用

配置 dws 登录授权后按工作流调用。

适合谁 & 边界

重度使用钉钉的团队。需要先完成 CLI 配置。
